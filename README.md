# 🌍 Air Quality Guardian: Smart Environmental Monitoring System

## 📖 Abstract
Air pollution is a major problem that affects human health and the environment.  
The **Air Quality Guardian** project monitors air quality, temperature, and humidity in real time using an **ESP32** connected to sensors and an LCD display.  
When pollution levels exceed safe limits, the system alerts the user through the display.  

This project demonstrates how **embedded systems and IoT** can be used to develop a **low-cost air quality monitoring system** for homes, classrooms, and offices.

---

## 🚩 Problem Statement
Air pollution and poor indoor air quality can cause health problems such as:
- Breathing difficulties  
- Allergies  
- Fatigue  

However, many people are unaware of the pollution levels around them because they lack monitoring systems.  
Therefore, there is a need for a **simple, affordable system** that can continuously monitor air quality and environmental conditions and alert users when levels become unsafe.

---

## 🎯 Objectives
- Monitor air quality using a gas sensor.  
- Measure temperature and humidity using a DHT sensor.  
- Display environmental data in real time using an LCD screen.  
- Develop a low-cost embedded monitoring system.  
- Demonstrate the use of IoT and control systems in environmental monitoring.  

---

## 🔮 Future Improvements
- Mobile app monitoring using IoT  
- Cloud data storage and analysis  
- Air purification system integration  
- Alarm or fan activation when pollution increases  
- Real-time pollution alerts via smartphone  
- Data logging for long-term analysis  

---

## 📌 Conclusion
The **Air Quality Guardian** project demonstrates how IoT and embedded systems can be leveraged to create a **low-cost, real-time environmental monitoring solution**.  
It provides a foundation for future enhancements such as mobile integration, cloud analytics, and automated pollution control systems.
